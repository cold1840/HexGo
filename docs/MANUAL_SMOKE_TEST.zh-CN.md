# 本地对局手工冒烟测试

运行 `cargo run`。提交影响本地对局 UI 的改动前，请完成以下检查。

## 启动与布局

1. 确认紧凑六边形网格显示在左侧，状态面板显示在右侧。
2. 确认所有棋盘边均清晰连接，没有重复或缺失的线段。
3. 将窗口缩小至允许的最小尺寸再恢复。棋盘必须始终居中、保持比例且完整可见。
4. 确认简体中文标签清晰可读。应用会依次查找思源黑体、Noto Sans CJK、文泉驿正黑、微软雅黑或苹方；如果均不可用，则先记录英文警告，再回退到 Bevy 默认字体。

## 鼠标对局

1. 悬停多个空交点。与当前执子方颜色一致的半透明棋子必须跟随最近交点。
2. 点击空交点。棋子必须出现，当前执子方必须切换，最后落子处必须显示橙色标记。
3. 点击已有棋子的交点。棋盘和当前执子方必须保持不变，面板必须显示交点已占用错误。
4. 完成一个简短提子过程。引擎接受落子后，被提棋子必须立即消失。
5. 在存在合适局面时尝试自杀和违反全局同形的落子。每次拒绝都必须保持棋盘与当前手不变，并显示对应错误。

## 键盘对局

1. 按 `Tab` 直到棋盘获得焦点。使用四个方向键移动交点焦点，并使用 `Enter` 或 `Space` 落子。
2. 使用 `Tab` 和 `Shift+Tab` 依次访问“停着”“认输”和“重新开始”。获得焦点的操作必须显示强调色边框。
3. 仅使用键盘激活每项操作。在确认框内按 `Escape`，确认对局状态没有变化。

## 终局与重开

1. 停着一次。计数必须变为 `1 / 2`，当前执子方必须切换。
2. 落下一子。停着计数必须恢复为 `0 / 2`。
3. 连续停着两次。此后必须禁止继续落子，结果面板必须显示胜方、胜差、棋子数、领地、贴目和总分。
4. 选择重新开始并取消，确认局面保留；再次选择并确认，确认恢复空棋盘、黑方先行和零停着计数。
5. 开始另一局，选择认输，先取消再确认。结果必须将对手显示为胜方，且不显示计分结果。
